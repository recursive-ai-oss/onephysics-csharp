# Third-party notices

## What the packages contain

`RecursiveAI.OnePhysics` and `RecursiveAI.OnePhysics.Tools` contain code written for this repository and nothing copied from elsewhere: no third-party source, no bundled binaries, no embedded data tables, no meshes, images or other assets. The algorithms come from published papers, talks and books, which are cited in comments and in the specifications under `docs/spec/`. Citing a paper is not a notice; no code from any physics or math library was read or used.

Nothing else is referenced at run time beyond the .NET base class library, which the application brings.

## What is in the repository but is not shipped

- **Test data and scenes** (`testdata/`, `scenes/`) are generated by code in this repository from checked-in seeds, or written by hand. They contain no third-party assets.
- **Benchmark projects** (`bench/`) compare this library with other engines through their public packages and release builds. Those are restored or built on the machine that runs the benchmark and are never committed, packed or redistributed. Their licences (MIT or Apache-2.0 for every one) do not restrict benchmarking. If a benchmark binary were ever distributed, it would carry its comparison packages' notices.
- **Smoke apps, fuzz targets and tools** are build and test tooling and are not packed. The fuzz projects use SharpFuzz (MIT) on the machine that runs them.

## If this changes

A bundled asset or any copied code gets its own entry here, with its source, its licence and the licence text it requires, before it is committed.
