# Importers (`RecursiveAI.OnePhysics.Interchange`)

Normative, language-neutral. Every importer reads one file format from text or bytes the host already holds, with no file system or network access (a host supplies meshes, tilesets and external buffers through delegates), and returns plain definitions. The output is a function of the input bytes and the options alone: the same bytes give the same definitions bit for bit on every platform, in the same order. Anything the format allows that the engine cannot express is returned in `Warnings` (`Code`, `Location`, `Message`) and the import goes on; anything invalid throws `InterchangeException` (`Format`, `Location`, message saying what was expected). No other exception comes out of an importer for any input (checked by fuzz targets `interchange-urdf`, `-mjcf`, `-gltf`, `-tiled`, `-ldtk`, and by mutation tests over every sample).

## Common rules

- **Numbers** are invariant-culture decimals that must be finite and within ±1e9; anything else is an error naming the attribute.
- **XML** is parsed with DTDs prohibited and no entity expansion; depth above 256 and text above 64 Mi characters are refused. **JSON** depth above 64 is refused. A GLB or glTF above 256 MiB is refused.
- **Order.** Output follows file order: URDF links are a depth-first walk from the root with children in joint order; MJCF bodies depth-first in document order (a body with several joints becomes consecutive links in joint order); glTF bodies in depth-first node order; map layers and objects in file order. Dictionaries are only looked up, never iterated.
- **Zero** is always positive zero in output that reaches the world (a negative zero would change a world hash).
- **Single precision.** Definitions are float32 and are computed in double first: rotations from the correctly rounded sine and cosine, inertia rotated and shifted in double (onemath), then rounded once.

## URDF → `ArticulationDef` (3D)

`UrdfImporter.Import(xml, UrdfOptions)` returns `Definition`, `LinkNames`, `JointNames`, `Warnings`. Units are the format's (m, kg, rad).

| URDF | Definition |
|---|---|
| link (root = the one link that is no joint's child) | `ArticulationLinkDef`; `FixedBase = UrdfOptions.FixedBase` (default true) |
| joint `revolute`, `continuous`, `prismatic`, `fixed` | `Revolute` (continuous: no limits), `Prismatic`, `Fixed`; `Parent` = the parent link's index |
| joint `origin xyz rpy` | `Origin`, `OriginRotation`; rpy is roll about x, then pitch about y, then yaw about z, all about the fixed parent axes: R = Rz(yaw) Ry(pitch) Rx(roll) |
| `axis xyz` (default 1 0 0), `limit lower upper` | `Axis`, `HasLimits`, `LowerLimit`, `UpperLimit` (required for revolute and prismatic; lower ≤ upper) |
| `limit effort`, `limit velocity` | `Drive.MaxForce`, `MaxVelocity` (the drive has no stiffness or damping until the host sets one) |
| `dynamics damping friction` | `Damping`, `Friction` |
| `inertial origin mass inertia` | `Mass`, `CenterOfMass`, `InertiaTensor` rotated from the inertial frame into the link frame (`I' = R I Rᵀ`); a link without a mass takes `UrdfOptions.MasslessLinkMass` (default 1e-3 kg) and an isotropic inertia of mass × 1e-4, so a frame-only link keeps the joint-space mass matrix non-singular |
| `collision origin geometry` | `ShapeDef.LocalPosition`, `LocalRotation`; `box` (size), `sphere`, `cylinder` (URDF axis z → engine axis y by a quarter turn about x), `mesh` (below) |
| `visual`, `material`, `transmission`, `gazebo`, `calibration`, `safety_controller` | ignored without a warning |
| `mimic` | warning `mimic-joint`; the joint moves freely |
| `floating` below the root, `planar` | warning; imported as fixed |
| unknown geometry | warning `unknown-geometry`; the shape is left out |

Meshes: `UrdfOptions.Meshes(name)` returns an `InterchangeMesh` (vertices and triangle indices) or null (warning `mesh-unresolved`, shape left out). A mesh becomes the convex hull of its vertices after `scale`. Errors: unknown link, a link with two parent joints, a loop, more than one root, a joint to itself, negative mass or limits, a zero axis.

## MJCF → `ArticulationDef` (3D)

`MjcfImporter.Import(xml, MjcfOptions)` returns `Definition`, `LinkNames`, `JointNames`, `WorldShapes`, `Gravity` (option element, default 0 0 −9.81), `TimeStep`, `Warnings`. The model keeps its own axes (z up); the host chooses the world's gravity.

- **Compiler:** `angle` (degree default) applies to joint ranges, `ref`, `springref`, `axisangle` and `euler`; `eulerseq` (default xyz): a lower-case letter turns about the already-turned axes (the next rotation multiplies on the right), an upper-case letter about the fixed axes (on the left); `inertiafromgeom` auto/true/false; `autolimits` (default true). `boundmass`, `boundinertia`, `settotalmass`, `fusestatic`, `balanceinertia` are reported (`compiler-*`) and not applied.
- **Default classes:** `default` elements nest by `class`; an element takes an attribute from itself, then its class, then the class's parents up to the root `default`; a body's `childclass` applies to everything inside it unless overridden. Supported for every element kind the importer reads (joint, geom, motor, position, velocity).
- **Orientation:** `quat` (w x y z), `axisangle`, `euler`, `xyaxes` (Gram–Schmidt), `zaxis` (shortest arc from +z); at most one per element.
- **Bodies and joints.** The top body under `worldbody` is the root (one is required; two or more are an error). A free joint on it makes a floating base (`FixedBase = false`); no joint, a fixed base at its pose. A hinge, slide or ball joint on the top body is an error. Below the root a body without joints is a `Fixed` link; one joint gives one link; `n` joints give `n` links, the first `n−1` carrying `MasslessLinkMass` and the last the body's mass, shapes and name. **The link frame sits at the joint's anchor** (`pos`) in the body's orientation, so shapes, centre of mass and inertia are shifted by the anchor; a following joint's link is offset by the difference of anchors, and a child body's origin by its offset from the parent's last anchor.
- **Joints:** `hinge` → `Revolute`, `slide` → `Prismatic`, `ball` → `Spherical` (a ball's `range` upper bound is `SwingLimit`); `range` and `limited` (auto: limited when `range` is given and `autolimits`), `damping`, `frictionloss` → `Friction`, `armature`, `ref` → `InitialPosition`, `stiffness` and `springref` → a position drive with that stiffness and target.
- **Geoms:** `plane`, `sphere`, `capsule` and `cylinder` (MJCF's z axis → the engine's y by a quarter turn about x), `box`, `ellipsoid`, `mesh`; `fromto` for capsule, cylinder, box and ellipsoid. `size`, `pos`, orientation, `friction` (first of up to three numbers; default 1). An ellipsoid collides as a 42-vertex hull (an icosahedron with its edges split once, scaled; inscribed, so slightly inside the ellipsoid) and has the ellipsoid's exact mass. A mesh collides as the convex hull of its vertices after the asset's `scale` and has the mass of its triangles (signed tetrahedra; a mesh that encloses no volume is an error). `plane` geoms and any geom of the world body are static: `WorldShapes` lists them (a plane has its pose folded into the plane equation). `contype`, `conaffinity` other than 1 give warning `contact-filter`.
- **Mass:** an `inertial` element (`pos`, orientation, `mass`, `diaginertia` or `fullinertia`) is used as given (rotated into the link frame); without one, or with `inertiafromgeom="true"`, the body's geoms are combined: each geom's mass is its `mass` or `density` (default 1000) × volume, its inertia the solid primitive's about its own centre, moved and rotated into the link frame and combined with `InertiaD.Combine`. A body with no mass takes `MasslessLinkMass`.
- **Actuators** (`actuator` element), looked up by `joint` name: `motor` → `Drive.MaxForce` from `forcerange` (else `ctrlrange`), warning `motor-actuator` (command it with `Articulation.SetJointForce`); `position` → `Stiffness = kp` (default 1), `Damping = kv`, `MaxForce`; `velocity` → `Damping = kv`, no stiffness. A `gear` other than 1 is not mapped (warning `actuator-gear`). Other actuator kinds, and actuators on tendons or sites, give `unsupported-actuator`. `contact`, `equality`, `tendon`, `sensor`, `keyframe`, `include`, `custom`, `extension`, `frame`, `composite`, `flexcomp`, `replicate`, `attach` are reported as `unsupported-*`; `site`, `camera`, `light`, visual and asset elements other than meshes are ignored.

## glTF physics → `Scene` (3D)

`GltfPhysicsImporter.Import(bytes, GltfOptions)` reads glTF JSON (UTF-8) or GLB and returns `Scene` (the public scene format, `Scene.CreateWorld3D` builds the world), `BodyNodes`, `BodyNames`, `Warnings`. Gravity is (0, −9.81, 0) (glTF is y up); material 0 is friction 0.6, restitution 0, then one material per `physicsMaterial` in order. Extensions: `KHR_physics_rigid_bodies` with `KHR_implicit_shapes` (Khronos, Release Candidate), and `OMI_physics_body` with `OMI_physics_shape` (older; motion `type` static/kinematic/dynamic, shapes by `collider.shape`).

- **Nodes.** World transforms come from `matrix` or `translation`/`rotation`/`scale` down the node tree of the chosen scene (`scene`, else 0, else every parentless node); a node reached twice or a loop is an error. A body's pose is its node's world translation and rotation (scale removed; a reflection folded into the scale); shapes keep the scale.
- **Bodies.** A node with `motion` is a body (dynamic; `isKinematic` or a mass of 0, which stands for infinite mass, → kinematic); its descendants' colliders belong to it until a descendant has its own `motion`. A collider with no moving ancestor is a static body of its own node. `mass` → `MassOverride`; `centerOfMass`; `inertiaDiagonal` with `inertiaOrientation` → `InertiaOverride`, `InertiaRotation` (a zero component, meaning infinite inertia, is ignored); `linearVelocity` and `angularVelocity` are in node space and are rotated to world axes. Every shape has density `GltfOptions.Density` (default 1000), which only matters where no mass is given. `gravityFactor` ≠ 1 is not mapped (warning).
- **Shapes** (scene kinds): `sphere` (radius × the largest scale), `box` (size × |scale|), `capsule` and `cylinder` (height along the node's y; radii × the larger of the x and z scales): a capsule with equal radii on its body's frame is the exact `capsule` kind, a cylinder at its body's origin the exact `frustum` kind; any other capsule or cylinder (rotated, offset, tapered) becomes a convex `hull` (a capsule from rings at 0°, 30° and 60° latitude of 16 points plus the poles on both end spheres; a cylinder a 24-sided prism) with warnings `capsule-hull` and `cylinder-hull`. `plane` (static only) becomes a half-space (finite extents ignored with a warning). A `mesh` collider reads `POSITION` (VEC3 float) and indices (unsigned byte, short, int; triangles, strips, fans) through accessors with every offset, stride and count checked against the buffer; it is the `mesh` kind on a static body, and the `hull` of all the primitives' positions on a moving body or with `convexHull`. Compressed or sparse accessors are errors. Vertices are transformed by the full node matrix, so mirrored nodes mirror the mesh.
- **Materials** `staticFriction`/`dynamicFriction` → friction (the dynamic value; a difference is warned), `restitution`; `frictionCombine`, `restitutionCombine`, `collisionFilters` and per-collider filters are reported and not imported.
- **Triggers** are reported (`trigger`) and left out. A static body left with no shape (a trigger-only node) is dropped.
- **Joints** (`KHR_physics_rigid_bodies` node `joint`, `connectedNode`, `physicsJoints[joint]`): each side's body is that node's owner body (a node with no body gets one static anchor body at the origin, `BodyNodes` −1). Anchors are the joint nodes' positions in their bodies' frames. Limits fix per-axis ranges (`min`/`max`; an axis in several limits takes their intersection): all three linear axes limited to 0 and no angular limit → `point`; all three linear axes at 0 and two angular axes at 0 with the third free or limited → a `swingtwist` joint whose twist axis is that third axis of node A's frame in world axes at the initial pose, twist limits from its `min`/`max` and swing half-angles of 1e-4 rad (a hinge); anything else (prismatic, weld, cones, soft limits `stiffness` imported as hard) → warning `joint-linear` or `joint-angular`, joint left out. `drives` → `joint-drive`; `enableCollision` → `joint-collision` (a scene's joined bodies never collide).

## Tiled and LDtk → `Map2D` (2D)

`TiledImporter.Import(text, MapOptions)` (TMX or TMJ, from the first character; orthogonal, finite, square tiles; the grid at most 1024 × 1024 and 65536 tiles) and `LdtkImporter.Import(projectJson, levelIdentifier, MapOptions)` / `ImportLevel(projectJson, levelJson, ...)` return a `Map2D`: `TileLayers`, `Objects`, `Points`, `Size`, `Warnings`, and `Apply(PhysicsWorld2D)` creating the bodies. Output is in metres with y up: pixel (px, py) of a map `H` pixels tall is `Origin + (px, H − py) / PixelsPerMeter` (default 16 pixels per metre, origin 0, 0). Tile layers become `TileGrid2D` data (`Tiles` row by row from the bottom, as `AddTileGrid` takes them), so merged edges and ghost-free seams are the engine's.

**Conventions** (ours; custom properties as text, booleans `true`/`false`):

- **Collision layers:** a Tiled tile or object layer (or group) with boolean property `collision`, a layer named `collision` or `collisions` (any case), or a name in `MapOptions.CollisionLayers`; an LDtk IntGrid layer with such a name. Other tile layers are visual and skipped.
- **Tiles (Tiled).** Each non-empty tile's kind comes from, in order: its string property `kind` (`solid`, `half` = bottom half, `slope-right` = rising to the right, `slope-left`, `none`); its collision editor shapes (one rectangle covering the tile = solid, covering its lower half = half, one right triangle = a slope; no shape group = solid; an empty group = no collision); otherwise polygon objects. A horizontal flip mirrors slopes; other flips, and tiles whose shapes are none of those, become static polygon objects (convex up to 8 points, else a static loop). A tile with boolean property `oneway` (or a layer with it) goes to a second grid named `<layer>:oneway` (`MapTileLayer.OneWay`), which `Apply` gives a one-way surface (direction +y: passable from below, landable from above). An external tileset comes from `MapOptions.Tilesets(source)`; without it its tiles are solid (warning `tileset-missing`).
- **Tiles (LDtk).** The identifier of each IntGrid value, lower-cased with `-`, `_` and spaces removed: `solid`; `half`, `halftile`, `halfbottom`; `slopeupright`, `sloperight`; `slopeupleft`, `slopeleft`; `oneway`, `onewayplatform`, `platform` (a solid tile on the one-way grid); `none`, `empty`. Value 1 without an identifier is solid; any other unknown value is solid with warning `intgrid-value`. The CSV is top row first.
- **Objects (Tiled).** On a collision layer, rectangles, ellipses (a circle when width = height, else a 16-gon), polygons (counter-clockwise after the y flip; a convex polygon of up to 8 points, or on a static body a loop of segments) and polylines (chains) become shapes; on any object layer an object with a string property `body` (`static`, `dynamic`, `kinematic`, `sensor`) does too. Point objects are `Points`. Rotation is Tiled's clockwise degrees about the object's origin, giving a counter-clockwise radian rotation.
- **Entities (LDtk).** Entities with a string field `body` are boxes centred at `px + (0.5 − pivot) × size` (or circles of radius min(w, h)/2 when boolean field `circle` is true); others are `Points`.
- **Shape properties:** `density` (default 1), `friction` (0.6), `restitution` (0), `oneway`. All custom properties are kept in `MapObject2D.Properties`.
- **Tile objects, polylines inside tile shapes, finite-extents layers** that cannot be expressed are reported and left out.
